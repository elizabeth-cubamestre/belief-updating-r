# Belief Updating Under Uncertainty

A simulation-based statistical analysis exploring how prior beliefs, evidence reliability, and sample size affect belief updating.

## Overview

How should a person update a belief when they receive new evidence?

This project uses probability, simulation, statistical inference, and visualization in R to explore how different combinations of prior beliefs and evidence affect posterior beliefs.

The project was motivated by my interest in computational approaches to human decision-making and belief formation. Rather than attempting to model the brain or clinical disorders directly, I use a simplified Bayesian framework to investigate how beliefs can change when new information is observed.

## Research Questions

1. How does the strength of a prior belief affect the amount of belief updating?
2. How does the reliability of new evidence affect posterior beliefs?
3. How does increasing the amount of evidence affect uncertainty?
4. Can simulated belief-updating behavior be predicted from prior strength and evidence reliability?

## Methods

The analysis uses:

- Bayesian updating
- Probability distributions
- Monte Carlo simulation
- Data manipulation with `dplyr`
- Data visualization with `ggplot2`
- Bootstrap confidence intervals
- Hypothesis testing
- Simple linear regression

All simulated data were generated in R. No human-subject data were used.

## Key Skills Demonstrated

**Programming:** R

**Statistics:** Probability, Bayes' rule, simulation, sampling distributions, confidence intervals, hypothesis testing, bootstrap methods, regression

**Data Science:** `dplyr`, `ggplot2`, reproducible analysis, data visualization

**Tools:** Quarto, RStudio, Git/GitHub

## Important Note

This project is an educational simulation of Bayesian belief updating. It is not intended to model clinical disorders, hallucinations, paranoia, or actual neural computation. The simplified framework is useful for exploring how mathematical assumptions about prior beliefs and evidence can influence updating behavior.
